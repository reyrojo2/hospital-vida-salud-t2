# Hospital Vida Salud — T2

Proyecto académico individual de Desarrollo de Aplicaciones Web II.

Caso: Hospital Vida Salud. Arquitectura de microservicios con Spring Boot, Gateway, Eureka, WebFlux, R2DBC, PostgreSQL, RabbitMQ y GitHub Actions.

El desarrollo se realizará por fases. Esta rama `main` contiene el punto de partida; los cambios de implementación se revisarán mediante ramas y pull requests.
